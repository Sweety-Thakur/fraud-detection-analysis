
# 📊 Fraud Detection Analysis on FinTech Dataset

## 📌 Overview

This project focuses on analyzing a financial dataset to identify potential fraud patterns and understand loan and repayment behavior. The analysis is performed using SQL and Excel on a dataset sourced from Kaggle.

---

## 🎯 Objectives

* Detect suspicious transaction patterns
* Identify users with repeated missed payments
* Analyze loan distribution across different cities
* Categorize loans based on risk level

---

## 🛠️ Tools & Technologies

* SQL (Joins, Aggregations, CTEs, Window Functions)
* Excel (Data Cleaning & Analysis)

---

## 📂 Dataset

* Source: Kaggle
* Data includes user information, loan details, and repayment records

---

## 🔍 Key Analysis Performed

### 1. Loan Amount Analysis

* Identified maximum and minimum loan amounts

### 2. Missed Payment Detection

* Found users who missed payments multiple times

### 3. City-wise Loan Distribution

* Calculated total loan amount issued per city

### 4. High-Value Loans by City

* Used window functions to identify highest loans in each city

### 5. Loan Risk Categorization

* Classified loans as *closed*, *risky*, or *ongoing*

### 6. Repayment Analysis

* Calculated total repayment amount for each loan

---

## 📈 Key Insights

* Certain users showed repeated missed payment behavior
* High loan amounts were concentrated in specific cities
* Loan categorization helped identify risky loans
* Repayment trends indicated potential financial risk patterns

---

## 📌 Conclusion
